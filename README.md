# 1 in 88 Billion / 880億分の1

Be born as a farmed animal and live the whole life. A free, single-file life simulator built from published animal-welfare research. English and Japanese.

農場の動物として生まれ、一生を見届けるシミュレーター。公表された動物福祉の研究にもとづく、1ファイルの無料アプリです。英語と日本語に対応しています。

- Play / 遊ぶ: open `index.html`, or the GitHub Pages link of this repository.
- Sources and what is still an estimate / 出典と、まだ推定のもの: [research.md](research.md)
- Contains death, disease, injury, mutilation and slaughter, described plainly. 死・病気・けが・身体の切除・屠殺の記述を含みます。
- The idea of living one random life comes from [1in8b.life](https://1in8b.life/). This project is not affiliated with it. All code, text and data here are new. 「ランダムに生まれて一生を生きる」という発想は 1in8b.life によるものです。関係はなく、コード・文章・データはすべて新しく作りました。
